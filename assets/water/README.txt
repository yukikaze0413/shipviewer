Place optional water surface textures in this folder.

Supported default file names:
- water_diffuse.jpg
- water_diffuse.png
- material.png
- water.jpg
- water.png

Recommended sources:
- ambientCG: https://ambientcg.com/
- Poly Haven: https://polyhaven.com/textures/

Use CC0 textures when possible. If you use CC-BY assets, keep the required
attribution with your release package.
